Where do I find it?
  • Google Calendar on a computer: Settings → your calendar → Integrate calendar → Secret address in iCal format.
  • iCloud: Calendar app → the calendar's info → Public Calendar on → copy the link.
  • Outlook: Settings → Calendar → Shared calendars → Publish a calendar → ICS link.

Anyone with this address can read that calendar, so it's stored on your account only and never shown again in full.

Sleep from Apple Health

An iPhone Shortcut can send last night's sleep each morning, so you don't have to type it. It uses your API token; nothing to install.

{% if not has_token %}

Create an API token first

{% endif %}
Set it up (about 3 minutes)
  1. Shortcuts app → Automation → + → Time of Day, e.g. 10:00 daily → Run Immediately.
  2. Add Find Health Samples: Type Sleep, Start Date is in the last 1 day, Value is not In Bed and is not Awake, sort by Start Date, oldest first.
  3. Add Get Item from List → First Item, then Format Date on its Start Date → Custom HH:mm. Do the same with Last Item and its End Date.
  4. Add Text: slept [first time]-[last time].
  5. Add Get Contents of URL: {{ api_url }}, Method POST, Header Authorization = Bearer <your token>, Request Body JSON with text = the Text.

Run it once by hand and compare with the Health app. Sleep logged twice for the same night is replaced, not doubled.
